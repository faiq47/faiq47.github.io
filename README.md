# Faiq Ahmed Siddique · Portfolio

**Live site:** https://faiq47.github.io
(hosted free on GitHub Pages from https://github.com/faiq47/faiq47.github.io)

## Files
- `index.html`: the page content (all sections)
- `style.css`: the "Neon Plum" theme, layout, animations and phone/tablet/desktop layouts
- `script.js`: terminal preloader, typing effects, live code editor, module filters, card tilt, particles, contact form
- `assets/profile.jpg`: the hero photo
- `assets/Faiq_Ahmed_Resume_2026.pdf`: the file behind the "Download Resume" button
- `assets/Udemy_Node_JS_Certificate.pdf` and `assets/udemy-certificate.jpg`: the Udemy certificate

## Updating the live site
1. Edit the files in this folder.
2. If you changed `style.css` or `script.js`, bump the `?v=` number on their links in `index.html` so visitors get the new version.
3. Publish:
   ```
   git add -A
   git commit -m "Update portfolio"
   git push
   ```
   GitHub Pages updates the live site within a minute or two.

## Changing things
- **Photo:** replace `assets/profile.jpg` with a portrait photo of the same name.
- **Colours:** edit the variables at the top of `style.css` (`--violet`, `--mint`, `--pink`, `--bg`).
- **Code sample in "How I work":** edit the `code` text in `script.js`.
